# דירה בהנחה 2026 · דשבורד נתונים

**A Hebrew data dashboard for Israel's "Dira BeHanacha" 2026 subsidized-apartment lottery — data, insights and recommendations, refreshed daily.**

דשבורד נתונים והמלצות שיעשו לכם שכל בכל הקשור להגרלת **דירה בהנחה 2026**: מסך אחד מרוכז עם כל המספרים החשובים, מוגש בעברית, מימין לשמאל, ומתעדכן מדי יום.

🔗 **גרסה חיה:** [yairixstudio.github.io/dira-behanaha-9218](https://yairixstudio.github.io/dira-behanaha-9218/)

> **שימו לב:** הדשבורד מוגן בקוד גישה. התוכן בעמוד מוצפן, ובלי הקוד לא ניתן לצפות בנתונים.

## מה יש בפנים

- **מדדי מפתח (KPIs)** — סרגל נתונים מרכזיים בראש העמוד
- **טאבים לניווט** — חלוקה לנושאים, כולל תפריט מותאם למובייל
- **טבלאות נתונים** — עם חיפוש, סינון ומיון בלחיצה על כותרת עמודה
- **קידוד צבע** — סימון ויזואלי של רמות תחרות וסיכויים (ירוק / כתום / אדום)
- **סימולטור** — כלי אינטראקטיבי להתרשמות מהנתונים
- **טיפים והמלצות** — כרטיסי מידע קצרים ופרקטיים
- **עדכון יומי** — הנתונים בעמוד מתרעננים מדי יום (ראו היסטוריית הקומיטים)

## פרטיות ואבטחה

- **הכול רץ בדפדפן** — אין שרת, אין קריאות רשת, אין אנליטיקס ואין מעקב
- **התוכן מוצפן** — הנתונים והקוד של האפליקציה שמורים בעמוד כ־blob מוצפן (AES‑256‑GCM, מפתח שנגזר מקוד הגישה באמצעות PBKDF2‑SHA‑256 עם 150,000 איטרציות), והפענוח מתבצע מקומית עם Web Crypto API
- **כניסה חוזרת מהירה** — לאחר הזנת קוד תקין הוא נשמר ב־localStorage של הדפדפן שלכם בלבד, כדי לדלג על מסך הנעילה בביקור הבא
- העמוד מסומן `noindex` ואינו מיועד לאינדוקס במנועי חיפוש

## הרצה מקומית

הפרויקט הוא קובץ HTML יחיד, ללא תלויות וללא build:

```bash
git clone https://github.com/yairixStudio/dira-behanaha-9218.git
cd dira-behanaha-9218

# אפשרות 1: פתיחה ישירה בדפדפן
open index.html

# אפשרות 2: שרת מקומי
python3 -m http.server 8000
# ואז לגלוש אל http://localhost:8000
```

גם בהרצה מקומית נדרש קוד הגישה כדי לפענח את התוכן.

## טכנולוגיות

- **HTML + CSS + JavaScript** בקובץ יחיד — ללא frameworks, ללא build וללא תלויות חיצוניות
- **Web Crypto API** — פענוח AES‑256‑GCM עם גזירת מפתח PBKDF2 בצד הלקוח
- **עיצוב רספונסיבי** — תצוגה כהה, RTL מלא, מותאם למובייל ולדסקטופ
- **GitHub Pages** — אירוח סטטי ישירות מה־repo
